Common CleanMyMac Login Problems
================================

Users may sometimes experience problems while accessing their account.

Forgotten Password
------------------

A forgotten password is one of the most common login issues.

To recover access:

#. Select the password recovery option.
#. Enter your registered email address.
#. Check your email inbox.
#. Open the password reset message.
#. Create a new password.
#. Try logging in again.

Incorrect Email Address
-----------------------

If login fails, confirm that you are using the correct email address.

Many users have multiple email accounts, so it is important to use the one connected with CleanMyMac.

Browser Issues
--------------

Sometimes browser settings can affect login functionality.

Possible solutions:

* Clear browser cache
* Update the browser
* Disable conflicting extensions
* Try another browser
* Restart the browser

Internet Connection Problems
----------------------------

A weak or unstable internet connection can prevent successful login.

Check:

* Wi-Fi connection
* Network settings
* Browser connectivity

Try again after restoring a stable connection.

Account Lock or Security Issues
-------------------------------

Multiple incorrect login attempts may temporarily restrict access.

If this happens:

* Wait before trying again
* Reset your password
* Contact customer support if needed
